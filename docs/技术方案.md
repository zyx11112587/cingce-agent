# 考公 RAG 技术方案

## 1. 技术栈

| 层 | 实现 |
|---|---|
| 语言 | Python 3.11+ |
| 文档解析 | Markdown、`pypdf`、`pdfplumber`、`python-docx` |
| 结构化存储 | SQLite |
| BM25 | SQLite FTS5 trigram + `bm25()` |
| 向量库 | FAISS `IndexFlatIP`，缺失时使用 NumPy cosine |
| 向量模型 | OpenAI 兼容 embeddings API 或 Sentence Transformers |
| 融合 | Reciprocal Rank Fusion |
| 服务 | 标准库 `http.server` |
| 生成 | OpenAI 兼容 `chat/completions`，可选 |

## 2. 数据接入

### Markdown 真题

沿用当前题库解析规则，识别 `qid`、题干、选项、答案、官方解析和图片。每道题生成 `question` 和 `explanation` 两个块。

### PDF

1. 使用 `pypdf` 按页提取文字。
2. 如果页面无文字，尝试 `pdfplumber` 回退。
3. 每个 Chunk 保留 `page_start`、`page_end` 和 `source_format=pdf`。
4. 如果整个 PDF 无可提取文字，明确报错并提示 OCR。

### DOCX

使用 `python-docx` 提取段落和表格，转换成统一 Chunk。

### 申论与政治理论

按文件路径推断 `doc_type` 和 `subject`，支持 `政治理论`、`申论` 等过滤条件。文本按约 900 字切块，保留 120 字重叠。

## 3. 索引结构

| 表/文件 | 作用 |
|---|---|
| questions | 行测题目、答案、解析和来源 |
| chunks | 题目、解析、知识点、PDF/DOCX 文档块 |
| search_fts | FTS5 trigram BM25 索引 |
| images | 图片与题目关系 |
| vector_map | FAISS/NumPy 向量 ID 与 chunk_id 映射 |
| data/index/vectors/index.faiss | FAISS 向量索引 |
| data/index/vectors/index.npy | NumPy 降级向量索引 |

## 4. 检索流程

```text
query
  -> BM25 Top-N
  -> embedding query
  -> vector Top-N
  -> metadata filtering
  -> RRF fusion
  -> Top-K evidence
```

RRF 分值：

```text
score = bm25_weight / (rrf_k + bm25_rank)
      + vector_weight / (rrf_k + vector_rank)
```

默认权重均为 `0.5`，`rrf_k=60`，可通过环境变量调整。

## 5. Embedding 配置

API 模式：

```text
EXAM_RAG_EMBEDDING_PROVIDER=api
EXAM_RAG_EMBEDDING_BASE_URL=http://127.0.0.1:11434/v1
EXAM_RAG_EMBEDDING_MODEL=bge-m3
EXAM_RAG_EMBEDDING_API_KEY=
```

本地模式：

```text
EXAM_RAG_EMBEDDING_PROVIDER=sentence_transformers
EXAM_RAG_EMBEDDING_MODEL=BAAI/bge-small-zh-v1.5
```

未配置时执行 `--skip-vectors`，系统只使用 BM25。

## 6. CLI 与 API

```powershell
python -m exam_rag.cli ingest --input xingcezhenti --input data/politics --input data/shenlun
python -m exam_rag.cli ask "如何理解中国式现代化？" --subject 政治理论
python -m exam_rag.cli ask "申论综合分析题怎么答？" --doc-type 申论
python -m exam_rag.cli serve
```

API 的问答响应包括：

- `answer`
- `citations`
- `retrieval_mode`：`bm25` 或 `hybrid`
- `hits[].retrieval`：BM25/vector 排名
- `vector_error`
